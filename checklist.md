# FPV Fixed-Wing Preflight Checklist

## Radio

- [ ] Correct model selected
- [ ] TX battery sufficient
- [ ] Arm switch is OFF
- [ ] Throttle is at idle

## Airframe

- [ ] Airframe and hinges sound
- [ ] Wing and tail are secure
- [ ] CG and payload checked
- [ ] Prop and motor are secure

## Power and control

- [ ] Flight battery charged
- [ ] Flight battery secured
- [ ] Antennas secure
- [ ] Controls move free/correct
- [ ] Receiver link healthy
- [ ] Failsafe checked

## FPV and navigation

- [ ] Video channel is clear
- [ ] Goggles and DVR ready
- [ ] GPS home set, if used

## Launch

- [ ] Launch mode and timer set
- [ ] Wind and airspace checked
- [ ] People and launch area clear
